For this assignment, I attached an MPU6050 accelerometer/gyroscope sensor to my Raspberry Pi and used a library to read data from the sensor via I2C and write it to a file. I had to configure my Raspberry Pi to enable I2C communication, however, instructions for doing this were provided via the assignment and there were no issues. The wiring for this project was quite simple (see attached schematic).

I mostly used code that was provided in a tutorial, however, I did spend some time delving into a couple of the constants I found in that code, trying to understand where they came from. I added comments to the file explaining what I was able to figure out.
